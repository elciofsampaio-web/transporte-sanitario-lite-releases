## Instalar

1. Abra o link no celular Android e baixe o arquivo.
2. Abra o APK. Se o Android pedir, permita instalar desta fonte.
3. Toque em **Instalar**.

O Lite é um aplicativo separado (`br.go.goianesia.transportesanitario.lite`).
Ele **não substitui e não altera** o aplicativo Transporte Sanitário original.

## Atualizar

Baixe pelo mesmo link e instale **por cima**. Não desinstale e não limpe os dados:
os registros ficam salvos somente no aparelho.
